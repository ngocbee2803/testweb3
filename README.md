Web3 Demo - MetaMask Connection
Overview

A simple Web3 application built with HTML, JavaScript, and Ethers.js v6 that connects to a MetaMask wallet and displays the user's wallet address and ETH balance.

Features
Connect to MetaMask
Display wallet address
Display ETH balance
Technologies
HTML5
JavaScript
Ethers.js v6
MetaMask
Usage
Install the MetaMask browser extension.
Open index.html in your browser.
Click Connect Wallet.
Approve the connection request in MetaMask to view your wallet address and ETH balance.
